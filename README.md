# pulsodeventas — sitio v1

Sitio estático (1 archivo HTML + favicon), ya armado con el copy y la identidad visual definidos.

## Cómo usarlo (retoma la guía de deploy en la Fase 5)

1. Descomprimí este zip directo en la carpeta `~/pulsodeventas-web` (la que crea la Fase 4 de la guía). Si la carpeta ya existe con otra cosa adentro, reemplazá el contenido por estos archivos.
2. Abrí `index.html` con doble clic para verlo en tu navegador antes de subir nada.
3. **Pendiente antes de publicar:** en `index.html`, buscá `TU_FORM_ID` (una sola vez, en el `<form action=...>`) y reemplazalo por el ID real que te da Formspree en la Fase 5 de la guía.
4. Seguí la guía desde la Fase 5 (Formspree) → Fase 6 (subir a GitHub) → Fase 7 (Vercel) → Fase 8 (dominio en GoDaddy).

## Si querés pedirle ajustes a Claude Code

Podés iterar sobre estos archivos igual que si Claude Code los hubiera generado: abrí una sesión de Claude Code adentro de la carpeta y pedile cambios en lenguaje natural ("cambiá el color de los botones", "el texto del hero es muy largo en mobile", etc.).
